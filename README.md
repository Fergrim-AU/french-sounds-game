# Французские звуки: карточная игра (свой сервер)

Файлы лежат в корне репозитория: server.js, index.html, package.json, render.yaml.
Локально: `npm install`, затем `npm start`, откройте http://localhost:3000
Render: Build Command `npm install`, Start Command `npm start`, тариф Free.
Игры хранятся в памяти сервера: при перезапуске или «засыпании» бесплатного хостинга текущие игры сбрасываются.
